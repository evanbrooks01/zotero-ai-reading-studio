# Screenshot slots

This directory is intentionally kept free of screenshots in the public starter release. Add sanitized screenshots from the current Zotero build using the filenames below; the two top-level READMEs already describe each slot.

| File | What to show |
| --- | --- |
| `01-settings.png` | Settings page with API URL and key blank or masked; show separate reading and translation model/reasoning controls. |
| `02-reader-ai.png` | PDF plus the fixed AI pane, including model/retrieval controls and a rendered answer. |
| `03-translation.png` | Translation pane with source, result, settings, and `放入对话` / `Add to chat`. |
| `04-translation-to-chat.png` | The resulting paper conversation after translation text is added. |
| `05-brief-question.png` | The contextual question editor appearing next to a selection in the online brief. |
| `06-history.png` | Multiple named sessions for one paper and the switch/delete controls. |

## Capture checklist

- Use the current release UI, not screenshots from an older plugin.
- Keep the PNGs around 1400-2200 px wide and crop out unrelated desktop content.
- Replace personal paper titles, account names, file paths, URLs, and API keys where needed.
- Keep the filenames stable so the README table remains accurate.

The temporary files created during local capture use the `_*.png` pattern and are ignored by Git.

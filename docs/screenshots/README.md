These sanitized screenshots are part of the current public project and are embedded in the two top-level READMEs. The source captures were uploaded under the local `image/` directory and copied here with stable names.

| File | What to show |
| --- | --- |

## Capture checklist

- Use the current release UI, not screenshots from an older plugin.
- Keep the PNGs around 1400-2600 px wide and crop out unrelated desktop content.
- Replace personal paper titles, account names, file paths, URLs, and API keys where needed.
- Keep the filenames stable so the README links remain accurate.

The temporary files created during local capture use the `_*.png` pattern and are ignored by Git. A history-list screenshot is not included because no current capture was supplied; the feature is documented in the usage text instead of showing a fabricated image.
